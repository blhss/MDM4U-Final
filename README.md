# MDM4U Final

This repository contains the original version of my high-school MDM4U research project and a later, revised analysis. The project explores the relationship between adolescent fertility and total fertility across countries and territories.

## What is in each folder?

| Folder | Purpose |
| --- | --- |
| [original/](original/) | The original school project, including the written analysis, Excel workbooks, SPSS output screenshots, source data, and reference material. |
| [improved/](improved/) | The revised research report, its raw data inputs, supporting figures, and documentation of data sources and definitions. |

### original

This folder preserves the project as it was originally completed. It includes the initial fertility analysis and comparisons involving legal marriage age, CSE-profile coverage, and geographic regions.

Use this folder to see the original work and compare it with the revised version.

### improved

This folder contains the later reanalysis using 2023 fertility data. The revision removes regional and income-group aggregate entries, adds economic and female education variables, and compares regression models on the same sample. It also reports robust confidence intervals and sensitivity checks.
