# MDM4U Final

Original MDM4U research materials exploring the relationship between adolescent fertility and total fertility, with additional comparisons by legal marriage age, CSE-profile coverage, and region.

## Contents

The `original/` folder preserves all 16 supplied project files under their original filenames, including the Word analysis, Excel workbooks, regression screenshots, source data, and reference material.

These files are archived as originally supplied. The analysis has not yet been revised or independently validated for this repository. Planned methodological improvements are not part of this initial archive.

Third-party data and reference documents retain their original ownership and applicable terms.
